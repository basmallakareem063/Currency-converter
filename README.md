# Currency Converter 💱

A simple and responsive Currency Converter web application built with **HTML, CSS, and JavaScript**.

## 📌 About The Project

This project allows users to convert an amount from one currency to another using exchange rates fetched from an external API.

The project was created to practice working with:

* Fetch API
* Async/Await
* Promises
* APIs
* DOM Manipulation
* Event Handling

## ✨ Features

* 🌍 Supports multiple currencies
* 💱 Convert between different currencies
* 🔄 Fetches exchange rates from an external API
* ⚡ Asynchronous data fetching using `async/await`
* 📱 Responsive design
* ✅ Simple input validation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Fetch API
* ExchangeRate API

## 🔗 API

Exchange rates are provided by:

[ExchangeRate API](https://www.exchangerate-api.com/)
